# Notification area and background operation

SyncForge shows an icon in the notification area of the taskbar (bottom right, possibly behind the **^** arrow).

- **Click the icon** – opens the window.
- **Right-click** – menu with **Open SyncForge**, **Sync all profiles now** and **Exit**.
- **Tooltip** – shows whether a sync is running.

> Tip: To keep the icon always visible, drag it from the overflow onto the taskbar, or turn it on under Windows Settings › Personalization › Taskbar › Other system tray icons.

## Only one instance

SyncForge always runs only once. If you start the app again (e.g. from the Start menu), the existing window is brought to the front.

## Exiting

**Exit** in the notification area menu closes SyncForge completely. Running syncs are cancelled – without leaving half-copied files. After that, no automatic runs happen until SyncForge is started again.
